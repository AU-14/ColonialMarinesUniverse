# Reaper animation previews

These GIFs show the approved web showcase design using CMU sprites. They are
illustrative previews, not recordings of the game client or proof of multiplayer
behavior. The game implementation uses procedural overlays and the actual target's
sprite.

- [Reanimation](reanimation.gif): the 120-second charge is compressed into eight
  seconds, followed by the release at normal speed.
- [Flesh rip](flesh-rip.gif): the four-second harvest and release at normal speed.

The Reaper stays adjacent to the corpse. Reanimation uses a low vascular wrap
that leaves the corpse visible. Flesh rip draws material inward before the limbs
are removed.
