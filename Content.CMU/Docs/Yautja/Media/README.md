# Bracer material studies

These two caption-free images were captured from a browser material study using the production `yautja_experiment_*` shader sources at 3.5 seconds. They illustrate shader materials in isolation; the complete in-game formations, world lighting and audio are demonstrated by the production showcase script in `Content.CMU/Tools/Yautja/`.

The floor is `Resources/Textures/Tiles/Basic/Dark/dark.png`, by AftrLite, CC0-1.0, from [Space Station 14](https://github.com/space-wizards/space-station-14). Its original attribution remains in `Resources/Textures/Tiles/Basic/Dark/attributions.yml`.

The projected wearer uses `Content.CMU/Resources/Textures/CMU14/Yautja/body.rsi/full.png`, credited in its existing RSI metadata to the active CMSS13 development team, CC-BY-SA-3.0, from [the CMSS13 predator sprite source](https://github.com/cmss13-devs/cmss13/blob/b3a7ffe2813a31ddcf429a5a864b4048851d66b0/icons/mob/humans/species/r_predator.dmi). The study masks, recolors and scans that sprite using CMU's projection shader.

The resulting images are distributed under CC-BY-SA-3.0. Existing sprite and audio license metadata is unchanged.
