# LV624 FOB layout

The active `CMUPlanetLV624` / `CMULV624` Lazarus Landing surface supports the same default-off
Distress Signal system as the other supported colonies. Its primary sites remain **Nexus**
(65.5, -77.5) and **Robotics** (-51.5, -70.5).

Deployment now uses a **40-tile radius**. Relay pools were reauthored outside both deployment areas
and support-gun reach; the older ten-tile layout and coordinate audit are superseded.
There are seventeen shared markers, with twelve relay choices per LZ, four per tier.

See [supported maps and authored relay coordinates](MAPS.md#lv624-lazarus-landing) for the current
positions, approach groups and mapping instructions. See [logistics](LOGISTICS.md) for physical
assembly and [evacuation](EVACUATION.md) for contested boarding. The inactive legacy CMU LV624
map and upstream RMC LV624 map remain outside the Distress Signal map list.
