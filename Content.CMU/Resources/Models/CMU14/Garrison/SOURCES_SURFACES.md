# Garrison printed props and floor coverings

41 draft assemblies use original source pixels on editable 3D geometry. None is approved as finished art.

New geometric work is contributed under CC0-1.0 to the extent separately licensable. Copied source pixels and derivative design retain the source licenses and attribution below. Cropped PNGs must be distributed with this attribution.

Surface artwork uses nearest-pixel planar projection, with alpha below 128 treated as a cutout. Front/back faces represent opposite views of the same physical printed surface. Partial translucent materials, live animation, powered state switching, detailed textile folds and unseen structure remain unfinished. No new assets use a generic inherited mapping.

## Map review refinements

Cafe/hotel use an explicit -90-degree physical correction and Open2 +90 degrees to attach to their inspected west/east walls. The room-side variant flips U to preserve text reading direction. The requisitions notice backing ends at Y -0.566, beyond the prison hull armor ribs at -0.560. Eight desk flags rest on exact tables. All 125 exact saved transforms remain unchanged. Crops and source pixels were rechecked byte-for-byte; see `surfaces-placement-audit.json`. All assemblies remain drafts.
