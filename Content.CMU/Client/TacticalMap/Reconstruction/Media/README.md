# Redux development captures

These are unedited in-game captures from September 22, 2026, showing the actual
Stable Garrison Redux reconstruction at whole-map and building scales.

They predate the current controls and drawing workflow. Rotate left/right,
Plan / 3D, Whole map, the Pan toggle, navigation arrows and preview orders shown
here have since been replaced by Top down, Reset, drag-to-pan, middle-drag orbit,
and pencil/text drafts with Send. These captures do not demonstrate the latest
tracked-icon fixes or establish current loading/frame-time performance.

The images contain the game's existing artwork rendered in the game client;
they do not add new gameplay art or change the source assets' licenses.
