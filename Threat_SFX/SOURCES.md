# Threat SFX Sources

This collection contains isolated vocalizations from one threat performer at a time. It excludes hordes, crowds, ambience, music, footsteps, weapons, impacts, and explosions.

## Collection Summary

| Category | Files |
|---|---:|
| Docile / Idle | 7 |
| Attacking / Aggressive | 5 |
| Hurt / Damaged | 6 |
| Death Gasp / Dying | 7 |
| **Total** | **25** |

All runtime and preview assets use OGG Vorbis. Source WAV and MP3 recordings were decoded and encoded as OGG without trimming, layering, pitch changes, or other creative processing.
