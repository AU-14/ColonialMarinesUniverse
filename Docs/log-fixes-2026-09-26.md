Local fixes for the September 26 server logs, client log, and gameplay reports.

These fixes were developed in the September 26 working tree and ported to current `master` for review. They have not been deployed to the live server. The original verification below records the development runs; PR-branch verification is recorded separately at the end.

| Report or log failure | Change |
| --- | --- |

| Deleted ID owner breaks state serialization | Track cards on their original owner and clear their references immediately during owner termination. |
| Deleted ladder climber breaks state serialization | Store the last climber as a weak network reference and clear completed/cancelled climbs. Dirty watcher changes. |
| IV update/localization touches a deleted patient | Detach without rip feedback for deleted patients and stop transferring immediately after detachment. |
| Explosion flood mutates a previously processed collection | Clamp the tolerance of already-destroyed blockers to zero. |

| Red injury vignette disappears | Keep the injury overlay driven by replicated damage instead of replacing it with the effective pain tier. Pain alerts and penalties remain separate. |
| OPFOR specialists cannot open their equipment rack | Add `AU14JobOPFORWeaponsSpecialist` to `AU14VendorWeaponsSpecialistGearBase` in `Content.CMU/Resources/Prototypes/CMU14/Economy/Vendors/generalvendors.yml`. The generic rack and all six faction variants inherit the fix. |
| Tanks can be repaired during combat | Add tank maintenance mode: five seconds to open/close panels, engine and weapon controls locked throughout, repairs allowed only while fully open, and 50% extra incoming damage while exposed. | Burst weapons turn into continuous rapid fire | Preserve the active burst's shot count, require a new trigger press for the next burst, finish an already-started burst after release, and enforce the authored burst cooldown. Give the common RMC gun base a 0.25-second cooldown; explicit weapon overrides remain. |
| Unfamiliar enemy uniforms should show question marks by default | Set `ForceOnForceUnidentifiedMarkerEnabled` to true in `Content.CMU/Shared/CCVar/CMUCCVars.Game.cs`. Existing saved player preferences remain effective. |
| FoF sides need coordinated dropship departures | The first LZ launch request opens a three-minute window and sends an ARES announcement to the opposing faction. Requests during that window use the same departure time. A late request starts a new window. Returns, hijacks, and other modes keep their normal launch behavior. |
| Disable the biohazard weedkiller canister in FoF | Cancel weedkiller deployment before creating its timer or effects when the current preset is ForceOnForce. Other modes retain weedkiller. |
| Opposing pilots can launch another faction's dropship without hijacking | Restrict navigation readers to the owning faction's FTL/pilot access and enforce authorization in the UI, launch/cancel, tactical landing, and gunship pilot paths. FoF opponents must complete hijacking even with captured credentials; existing completed hijacks in other modes remain usable. |
| OPFOR gunship does not initially land on its carrier | Assign prebuilt single-deck gunship controls, access readers, and pilot seats to their loaded faction before initial deployment. Use the correct destination type for fighters and dropships. |
| UA-635C static gauss turrets cannot be hit by bullets | Add the missing bullet collision layer to the static turret fixture. The WY variant inherits the fix; real rifle and AP projectiles now collide, deal damage, and destroy both variants. |
| Explosions rarely sever limbs | Increase explosion severance accumulation on arms, legs, hands, and feet with `cmu.medical.severance.explosion_limb_multiplier` (default 4). Also exclude unsupported damage types from the human damage cap, fixing structural-heavy tank blasts. Head/torso severance policy remains unchanged. |
| Shuttle interiors have no authored air | Save atmosphere generated by the game's own rebuild routine in five escape pod maps, the lifeboat, ERT response shuttle, and WY transport. |

Remaining evidence and limits:

- Many deployed-server exceptions name `CMUCombatHearingSystem.IsProtected` / `IsSuppressed`. That system was absent from the original investigation checkout; current `master` contains it and separate fixes. This PR does not claim that its focused regressions reproduce those deployed-server failures.
- The ordinary mind/body deletion regression passes. This does not prove every reported MindComponent serialization failure has the same cause. Localization errors involving an invalid entity without a content caller also remain untraced.
- Insurgency falls back to a DistressSignal objective master, and no usable CLF final objective is configured in the inspected content. Choosing a replacement victory objective would change game rules; it has not been guessed or silently disabled.
- `ahelp.admin_prefix_webhook` is an obsolete setting in the deployed configuration. It is absent from the repository configuration, so the deployed server config still needs that key removed.
- Packet drops, malformed/unhandled network packets, closed-channel engine sends, PVS recovery requests, and “Cannot keep up” warnings are not established as resolved by these content fixes. They require a new live capture after deployment. RobustToolbox was not edited.
- Late typing/EUI messages can arrive after a body or UI has gone away. Permission-denied console messages and querying a server-only atmosphere CVar in a client console are not gameplay defects.

No live round, deployment, or complete gameplay test suite was run. Existing unrelated changes in the checkout were preserved.
