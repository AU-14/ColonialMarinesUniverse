CMU · lobby · players + round time

The readout, not a tab

Players and round time currently share the SERVER INFO heading line, competing with the title for a row that was never wide enough for three things. Rather than give each of them a position on the switch — where they would be a room with one line in it, and where you would only see them when that position happened to be selected — this puts them on the case, where they are readable whichever panel the screen is showing. Everything else here is the column as it is actually built now.

Why not tabs. A tab is a place you go. Round time and player count are things you want in the corner of your eye while doing something else — picking a character, reading the round info, typing in chat. Putting them behind a selector means they are invisible exactly when they matter, and the round clock already has a large dedicated panel elsewhere in the lobby, so a Time tab would be the same fact in a worse place.
Lit vs printed is a real choice, not a detail. Printed says these are labels on a box: quiet, always there, never competing with the screen. Lit says they are live instruments, which is truer — the numbers do change — and it suits the equipment, but it puts a second glowing thing next to the main screen, and this panel has spent a lot of effort establishing that lit means screen and unlit means case.
Placement changes what it reads as — but two of the three do not survive the real column width, which is what this sketch is set to. On the plate it would be nameplate furniture like the serial, except the fixed name is long enough that the readout wraps it onto two lines and still clips the round time. Beside the switch is the most compact, but the same clipping happens: "NOT STARTED" is about the longest round-time string and there is not room for it next to a two-position switch. Its own row is the only one that fits both fields whole, and it is also the one that reads as an instrument rather than as decoration.
What this can't show: the in-game scanline grain over the readout glass, and what a long value does to it — "NOT STARTED" is about the longest round-time string, but a player count on a full server is wider than the "1 (0 ready)" here.
